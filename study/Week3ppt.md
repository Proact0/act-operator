### 슬라이드 3: 미들웨어 시스템 개요
**슬라이드 내용**
- 흐름 중간에 로직 수행 가능
- 안전장치, 모니터링, 변환 기능 제공
- 에이전트 수정 없이 기능 확장
- **안전/안정/컨텍스트** 3대 카테고리

**시각적 제안**
- 레이아웃: 3열 카드 레이아웃 (안전, 안정, 컨텍스트)
- 시각 요소: 각 카테고리별 직관적 아이콘 (방패, 그래프, 말풍선)
- 강조: "에이전트 수정 없이" 문구를 볼드 처리

---

### 슬라이드 4: 미들웨어 훅(Hook) 타입
**슬라이드 내용**
- **Node-style**: 특정 시점 실행
- `before_agent`, `after_model` 등
- **Wrap-style**: 호출 자체를 감싸기
- `wrap_model_call`, `wrap_tool_call`

**시각적 제안**
- 레이아웃: 2열 비교 레이아웃
- 시각 요소: ReAct 루프 내부에서 훅이 끼어드는 지점을 표시한 워크플로우 다이어그램
- 전환 문구: "이 훅들이 어떤 순서로 실행되는지 다음장에서 보겠습니다."

---

### 슬라이드 5: 실행 순서: 양파 껍질 구조
**슬라이드 내용**
- `before_*`: 등록 순서대로 실행
- `wrap_*`: 층층이 감싸는 구조
- `after_*`: 역순으로 최종 확인
- 핵심 미들웨어는 리스트 앞에 배치

**시각적 제안**
- 레이아웃: "양파 껍질" 모양의 동심원 다이어그램
- 시각 요소: 외부에서 내부로 들어오는 화살표(`before`)와 내부에서 밖으로 나가는 화살표(`after`)
- 강조: "핵심은 가장 바깥층(앞)"을 빨간색 강조선으로 표현

---

### 슬라이드 6: Human-in-the-Loop (HIL)
**슬라이드 내용**
- 민감한 작업 전 사용자 승인
- `approve`, `edit`, `reject` 결정
- 체크포인터(Checkpointer) 필수 사용
- 에이전트 상태의 영속성 보장

**시각적 제안**
- 레이아웃: 상단 프로세스 바 + 하단 3개 버튼 디자인 (Approve, Edit, Reject)
- 시각 요소: 이메일 전송 전 팝업창이 뜨는 모바일 목업 이미지
- 강조: "체크포인터 필수"를 경고 아이콘(`⚠️`)과 함께 강조

---

### 슬라이드 7: 토큰 절약과 정보 보호
**슬라이드 내용**
- **SummarizationMiddleware**
- 긴 대화 자동 요약 및 압축
- **PIIMiddleware**
- 이메일, 카드번호 등 가림 처리
- `redact`, `mask`, `block` 전략

**시각적 제안**
- 레이아웃: 좌측 요약 프로세스 애니메이션 + 우측 마스킹 예시 테이블
- 시각 요소: 긴 채팅창이 짧은 요약문으로 변하는 GIF 형태의 일러스트 제안
- 전환 문구: "이제 우리만의 고유한 로직을 추가하는 방법을 알아볼까요?"

---

### 슬라이드 8: 커스텀 미들웨어와 상태 확장
**슬라이드 내용**
- `AgentMiddleware` 클래스 상속 구현
- `Agent Jump`를 통한 조기 종료
- 전용 상태 필드(`CustomState`) 추가
- 유연한 비즈니스 로직 적용 가능

**시각적 제안**
- 레이아웃: 좌측 코드 스니펫 (간결한 상속 예시) + 우측 점프 로직 다이어그램
- 시각 요소: "BaseNode -> CustomMiddleware -> End" 흐름도
- 강조: `jump_to: "end"` 코드 부분을 하이라이트

---

### 슬라이드 9: 조건부 분기와 Persistence
**슬라이드 내용**
- `conditions.py`: 라우팅 로직 정의
- 결과에 따른 다음 노드 결정
- `MemorySaver` / `SqliteSaver`
- 타임 트래블: 이전 상태 복구

**시각적 제안**
- 레이아웃: 복잡한 신경망 구조에서 특정 경로가 빛나는 다이어그램
- 시각 요소: 분기점(`Decision Diamond`)과 결과 노드 매핑 테이블
- 전환 문구: "오늘 배운 모든 내용을 하나의 과제로 녹여보겠습니다."
